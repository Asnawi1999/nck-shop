NCK SHOP — PROFESSIONAL RESPONSIVE HTML DEMO
Files:
- index.html: Public product page (customer view)
- admin.html: Simple product editor (owner prototype)

How to preview:
1. Extract the ZIP file.
2. Open index.html to view the public shop.
3. Open admin.html to edit product name, description, price, stock display and image.
4. Save changes. For this demo, the data is stored only in local storage in that browser/device.

Important:
This is a visual/front-end prototype only. It does not have secure admin authentication, shared online database, real stock sync, order saving, email notifications or payment processing. Do not publish admin.html as a private admin system. To go live safely, we must add backend authentication, database access rules and a supported payment provider.
